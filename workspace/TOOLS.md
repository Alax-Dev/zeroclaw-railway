# TOOLS.md - Zeroclaw Environment

## Environment
- **Platform:** Railway (Docker)
- **OS:** Linux (Debian-based)
- **Runtime:** Node.js 22

## Available Tools
- git, curl, wget, python3, pip, node, npm
- Full OpenClaw tool suite (exec, web_fetch, browser, etc.)

## API Keys
- NVIDIA NIM: Set via NVIDIA_NIM_API_KEY env var
- GitHub Models: Set via GITHUB_TOKEN env var
- Telegram: Set via TELEGRAM_BOT_TOKEN env var
